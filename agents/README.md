# agents/ — AI 编程工具共享参考

本目录是**唯一被 git 跟踪**的 AI 编程辅助资料目录，供 ZCode、Claude Code、
WorkBuddy 等各类 AI 编程工具与人类协作者共用。各工具的私有记忆目录
（`.zcode/`、`.claude/` 等）默认不入库；跨工具、跨会话需要沉淀的项目级
经验写在这里。

## 维护规则

- 只收**项目级**内容：踩过的坑与根因、验证过的操作方法、选型背景。
  通用编程常识不收；**个人开发机的环境配置与资源差异**（有无
  docker/MySQL、代理、算力等）不收——那是各人自己的事。实现细节归代码
  注释；工程约定（怎么改代码）归根目录 `AGENTS.md`。本目录定位是
  「**事后才知道的教训**」——约定教你做对，教训记你为什么错。
- **保持更新**：过时内容删除，项目经验保留；每次踩坑核实后回写一条，
  一条一个根因，不复述事故过程。
- AI 生成的分析/评审报告默认**不入库**；确有沉淀价值的，蒸馏成条目
  写进 `lessons.md`，原文件丢弃。
